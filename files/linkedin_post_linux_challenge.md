🐧 Just wrapped up the Linux Challenge for DevOps Students — a solid hands-on run through core sysadmin and automation skills.

What it covered:

✅ Linux fundamentals — directory structures, file permissions, and ownership
✅ User & group management — creating users, assigning groups, and setting directory access
✅ Process management — running, monitoring, and killing background processes
✅ Networking — checking configs, testing connectivity, listing open ports, and configuring ufw for HTTP/HTTPS
✅ Shell scripting — wrote and tested:
   • backup.sh — compresses a project directory into a tar.gz with error handling
   • cleanup.sh — auto-deletes backups older than 7 days, scheduled via cron
   • rotate_logs.sh — rotates log files once they cross a size threshold
✅ Advanced automation:
   • resource_monitor.sh — tracks CPU, memory, and disk usage on a schedule
   • email_alert.sh — sends alerts when CPU or disk thresholds are breached
   • bulk_user_add.sh — bulk-provisions users from a list with groups and home directories

This challenge really reinforced that strong Linux fundamentals are the backbone of DevOps — automation, monitoring, and infrastructure work all build on this foundation.
